Red Flannel Hash (Connecticut)

The boiled dinner's leftovers, beets and all, fried to a crust. There are dishes a state is famous for and dishes a state actually eats, and Red Flannel Hash (Connecticut) is the second kind — which, in Connecticut, is the only kind this reference counts.
